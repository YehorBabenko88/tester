# Official source availability audit — 2026-11-07

AVAILABLE means an official source and sample retrieval were verified, not complete all-symbol coverage. PARTIAL means limited category, retention, resolution, snapshots only or incomplete archive coverage. UNAVAILABLE means the documented route does not provide the requested category/history. UNVERIFIED means no downloadable official historical sample was established. Initial dates below are per named sample and resolution; the exchange does not promise one global inception date for all symbols. Evidence JSON preserves exact URLs and checked times.

## Operational limits and evidence

The [official IP limit](https://bybit-exchange.github.io/docs/v5/rate-limit) is 600 requests/5s; the downloader intentionally defaults to3/s with a shared throttle. HTTP429/5xx/network failures retry with bounded exponential backoff; Retry-After and Bybit rate-limit errors are handled. HTTP403 can indicate IP protection; it triggers a10minute backoff rather than rapid retries. Archive throughput and HTTP Range support have no universal guarantee; each resume probes for206 and validates a strong ETag.

Live tests: 2024-01-01 00:00–00:05 UTC candle windows, page limit2 to force pagination, across Spot/Linear/Inverse and supported price types; OI/ratio five5min points; funding one day. Re-run checks used the same journal. Five core archive files plus a headerless MT4 sample were verified. Boundary evidence uses monthly probes from epoch and exact archive listings, not blanket start-date assertions. The complete matrix does not mean all sources are implemented: portal history, ZIP, historical liquidations, delivery backfill, Option data and B's PostgreSQL adapter remain outside this implemented core and are explicitly qualified above.
