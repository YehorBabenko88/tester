# Platform Implementation Plan

> For agentic workers: use superpowers:executing-plans to implement task by task.

**Goal:** Deliver local API, durable jobs, Windows lifecycle and verifiable acceptance as a Draft PR.
**Architecture:** FastAPI plus PostgreSQL queue and supervised worker; adapter interfaces connect other workstreams.
**Tech Stack:** Python 3.11+, FastAPI, psycopg, pytest, PowerShell, GitHub Actions.
**Spec:** docs/superpowers/specs/2026-11-07-platform-design.md

## Global Constraints
No live trading, secrets in git, merges or deployment on this physical host. Separate tester_platform schema. No fabricated market data. end_ms exclusive. Existing shared storage ownership remains with B.

## Review Focus
Lease fencing after pause/recovery; untrusted browser writes; cleanup symlinks; installer partial failure; unavailable integrations.

### Task 1: API and configuration
Files: src/api/config.py, models.py, main.py, providers.py; tests/platform/test_api.py.
Produces create_app(settings, provider), versioned OpenAPI and provider interface. Test invalid ranges, loopback origins, all endpoints, absent providers and pagination. First run failing tests, implement, run suite, commit.

### Task 2: Durable queue and workers
Files: src/api/db.py, jobs.py, worker.py, migrations/; tests/platform/test_jobs.py.
Consumes validated DownloadRequest; produces queue create/get/transition/claim/checkpoint/finish. Test PostgreSQL transactions, migrations repeated, concurrent claims, expired leases, pause fencing, retry, failed jobs and graceful stop. Run failing tests first, implement, verify real PostgreSQL, commit.

### Task 3: Windows lifecycle and operations
Files: scripts/windows/*.ps1, src/api/supervisor.py, maintenance.py; tests/platform/test_operations.py; docs/operations.md.
Consumes config/migration/worker CLI. Test actual quota/cleanup behavior, failed configuration and supervisor shutdown. Implement setup/start/stop with restricted secrets, database ownership guards and restart limits. Verify PowerShell parsing and disposable install acceptance, commit.

### Task 4: CI, contracts and acceptance
Files: .github/workflows/platform.yml, scripts/acceptance.py, contracts/v1/openapi.json, docs/api-contract.md.
Consumes all prior deliverables. Run lint, unit, integration, migration, contract, security and Windows checks. Export schemas; record observed results and remaining cross-workstream gaps. Whole-branch review, fixes with tests, push feature branch and create Draft PR into main. Never merge.
