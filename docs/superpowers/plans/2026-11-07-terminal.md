> Execute with superpowers:executing-plans, inline as authorized by the user.

**Goal:** Production client for E API with truthful market, download and analytical views.
**Architecture:** ES modules, dependency-free canvas charts, schema-validating API adapter, virtualized screener. No backend implementation. Fixtures only in tests.
**Tech Stack:** Browser ES modules, Canvas2D, Node test runner, Playwright.
**Spec:** ../specs/2026-11-07-terminal-design.md plus approved requirements in Issue #4 (precedence).

## Global Constraints
UTC epoch ms; [start_ms,end_ms); exact decimal strings kept in transport, no financial computation in JS. Number conversion is drawing-only. A/B/C/E own data. Only this branch/repository. No deployment/merge.

## Review Focus
Missing/partial/corrupt data never becomes complete; selection persists across pages; stale requests do not repaint new selections; unknown totals never display 100%; long ranges never trigger tick downloads.
