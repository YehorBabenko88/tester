# Storage Implementation Plan

> For agentic workers: use superpowers:executing-plans inline. User explicitly authorized implementation and automated tests.

**Goal:** durable Bybit storage, evidence-based coverage and recovery.
**Architecture:** psycopg 3, schema tester_storage, immutable raw records and transactional publication; optional TimescaleDB only.
**Tech Stack:** Python 3.11+, PostgreSQL 14+, unittest, SQL migrations.
**Spec:** docs/storage/contract.md and approved user contract (2026-11-07).

## Global Constraints
Work only in B-owned src/storage, src/quality, storage tests/docs and dedicated CI. No merge, destructive provisioning, secrets in logs/files, invented timestamp precision or empty=COMPLETE. DSN TESTER_STORAGE_DSN or libpq service. Scope migration schema, never existing app tables.

## Review Focus
Conflicting replay must preserve old data and a durable finding. UTC W/M closure must be calendar-aware. Empty and sparse data must remain unverified. A process kill must not advance checkpoints. Restored backup must contain committed raw/provenance/checkpoint state.
